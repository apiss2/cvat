# モデルの登録、更新、実行

[モデル管理](README.md)

このページは導入済みのモデル管理を使うメンバー向けです。推論コードを作成する場合は[モデルの実装仕様](model-development.md)、環境を準備する場合は[配備](deployment.md)を参照してください。

## モデル管理を開く

CVATへログインし、上部メニューの「モデル管理」を開きます。同じCVATのログイン状態を使用し、別のパスワードや個人用トークンは入力しません。
セッションが失効した場合は「CVATへ戻る」でログインを確認します。接続エラーが続く場合は、表示内容を管理者へ伝えてください。

一覧ではモデル名、種類、作者、連絡先、公開状態を確認できます。公開前や登録に失敗したモデルは、所有者と管理者だけが確認できます。
連絡先は作者が記入した内容だけを共有し、CVATのメールアドレスを自動公開しません。

## 新規登録に必要なもの

| 入力 | 内容 |
|---|---|
| モデル名、説明、連絡先 | 用途、対象、使用条件を説明します。連絡先は任意です。 |
| モデルの種類 | Segmentation、Detection、Classificationから選びます。 |
| クラスIDとラベル名 | 推論コードの出力に対応するラベルを登録します。 |
| 推論コード | model.pyを用意します。 |
| ONNXファイル | 使用するファイルを1個から16個まで指定します。 |
| 試験画像 | PNGまたはJPEGを1枚指定します。実際の対象を含む画像を使います。 |

登録フォームが設定からマニフェストを作成するため、ブラウザーでmanifest.jsonをアップロードする必要はありません。
ファイルは個別に指定します。ZIP登録、追加のPython依存パッケージ、補助Pythonモジュールの新規登録には対応していません。詳細な上限は[実装仕様](model-development.md)を確認してください。

Segmentationではラベルを出力する順に上から登録し、ポリゴンの頂点間隔と最小面積を設定します。間隔を大きくすると細かな凹凸が省略され、小領域も消える場合があります。領域内の穴はポリゴンに保持されません。
DetectionとClassificationでは、クラスIDを推論コードの出力と一致させます。Classificationにはポリゴン変換設定を使用しません。

「検証して公開」を実行すると、管理サーバーがファイルと試験推論の結果を検査します。成功後にモデルが公開されます。検証に失敗した場合は、詳細な推論結果と処理ログを確認します。
公開済みの版がない登録は更新できないため、修正したファイルを新しいモデルとして登録してください。

## 公開済みモデルを更新する

同じモデルの詳細で「このモデルを更新」を選び、変更するファイルまたは設定だけを指定します。未選択の推論コード、ONNXファイル、試験画像、既存の補助モジュールは公開中の版から引き継ぎます。
設定だけ、推論コードだけ、試験画像だけ、複数のONNXファイルだけの更新もできます。

ONNXファイル名は、大文字と小文字を含め既存名と完全に一致させます。差し替える推論コードはmodel.pyです。ONNXファイルの追加、削除、改名はこの更新ではできません。
全ファイルを差し替える場合も、同じ更新画面を使用します。「新しいモデルを登録」から送ると別モデルになります。

更新が成功すると新しい版を公開します。失敗した場合や他の更新と競合した場合は、既に公開されている版を上書きしません。変更がない要求は受け付けません。
モデルの登録、更新、削除、公開版の切り替えにCVATの再起動は不要です。管理サーバーが受理した登録処理は、画面を閉じても継続します。

## 試験結果と過去の版を確認する

詳細画面で試験する版と画像を選びます。DetectionとSegmentationは図形、Classificationはタグ名と信頼度を確認します。JSON形式の推論結果と処理ログは詳細表示から確認できます。
Classificationの信頼度は試験結果で確認できますが、CVATのタグへ信頼度用の属性を自動追加する機能ではありません。

過去の版に戻す場合は、保持されている版を選び、試験結果を確認して公開先を切り替えます。モデルを更新しても、既に処理中の一括推論が参照する版は変わりません。
新しい版を使う場合は、CVATの実行画面でモデルを選び直します。一覧の反映には定期更新と通信に要する時間がかかります。

## CVATでモデルを実行する

AI実行画面で公開モデルを選び、モデルの出力ラベルとタスクのラベルを対応付けます。Classificationはタグ用ラベルへ対応付け、画像または動画の各フレームにタグを付けます。
画像全体を分類する場合はROIを指定しません。ROIを指定した場合は切り出した画像を分類しますが、タグの出力先はフレーム全体です。

登録したSegmentationモデルの結果は既にポリゴンへ変換されています。CVAT側でマスクからポリゴンへの追加変換を行う必要はありません。
この登録機能のモデルでは、CVATの画面から信頼度の閾値を変えても追加の選別は行いません。選別は推論コードが実装します。
タグ条件と画像ごとの選択を使う操作は[選択実行](../annotation/selective-ai.md)にあります。通常の自動アノテーションとは保存と中止の扱いが異なります。

## 操作権限と削除

更新、削除、試験、版の操作、ログの閲覧は所有者と管理者が行えます。公開モデルはCVATの利用者や組織ごとに非公開にする構成ではありません。公開範囲は[セキュリティ](security.md)を参照してください。

モデルを削除すると全ての版の新規推論を拒否しますが、保存済みのCVATアノテーションは残ります。既に受理された推論は完了する場合があり、実行中の一括推論は後続の画像で失敗する可能性があります。
一括処理を完了させる場合は、その終了後に削除してください。画面上の削除では重みを物理削除しません。保存容量の回収は管理者向けの[保守手順](operations.md)に従います。
