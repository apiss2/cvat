# アノテーション操作の拡張

[ドキュメントの入口](../README.md)

導入済みのCVATで使う独自操作を説明します。管理者による有効化は[UIプラグインの案内](../../cvat-ui/plugins/README.md)を参照してください。

| 操作 | 説明 |
|---|---|
| [フレーム移動用フィルター](frame-navigation-filter.md) | タグなどの条件で移動し、他のアノテーションも表示します。 |
| [選択した画像への自動アノテーション](selective-ai.md) | 条件に合う画像を選択し、結果をサーバーへ順次追記します。 |
| [SAM2とSAM3.1の追跡](tracking.md) | 選択した図形を追跡し、結果を確認して手動で保存します。 |

選択実行と追跡では保存と中止の動作が異なります。各ページの説明を確認してから実行してください。
