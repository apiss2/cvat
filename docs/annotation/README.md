# 追加したアノテーション操作

[追加機能の一覧](../README.md)

導入済みのCVATで使う操作をまとめています。機能が画面にない場合は、管理者が[機能の管理一覧](../extensions/management.md)に従って有効にします。

## データと説明を取り込む

| 操作 | 内容 |
| --- | --- |
| [DICOM取り込み](dicom-import.md) | DICOMの静止画と動画からタスクを作成します。 |
| [アノテーション取り込み](../extensions/project-annotation-import.md) | プロジェクト内の既存タスクへアノテーションを追加または置換します。 |
| [タスク説明の一括登録](../extensions/task-guide-import.md) | MarkdownやJSONから作業説明や検査レポートを登録します。 |

## 画像を確認して編集する

| 操作 | 内容 |
| --- | --- |
| [フレーム移動](frame-navigation-filter.md) | タグなどの条件で画像を移動し、他のアノテーションも表示します。 |
| [長さの表示](physical-measurements.md) | 保存済みの画素間隔から、折れ線の長さをmmで表示します。 |
| [タスク情報の表示](../extensions/task-context.md) | 作業説明や検査条件をタスク詳細と作業画面で確認します。 |

## モデルを使って作成する

| 操作 | 内容 |
| --- | --- |
| [画像を選んで実行](selective-ai.md) | タグの条件や画像一覧で対象を選び、自動アノテーションを実行します。 |
| [動画の追跡](tracking.md) | 開始画像の図形を追跡し、新しいポリゴントラックを作成します。 |
| [モデル登録](../model-registry/README.md) | ONNXモデルを登録してCVATから使えるようにします。 |

画像を選ぶ自動アノテーションは結果をサーバーへ順次追記します。動画の追跡は全範囲の成功後に画面へ反映し、手動で保存します。中止時の扱いも異なるため、実行する操作の説明を確認してください。

## 結果を出力する

| 操作 | 内容 |
| --- | --- |
| [条件付きエクスポート](filtered-export.md) | 条件に合う画像と、その画像のアノテーションを出力します。 |
| [専用形式の入出力](../itgformat/README.md) | 独自形式「ITGformat」で領域と矩形を読み書きします。 |
