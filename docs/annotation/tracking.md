# SAM2とSAM3.1の追跡操作

[アノテーション操作](README.md) / [SAM2](../sam2/README.md) / [SAM3.1](../sam31/README.md)

開始フレームのポリゴンまたはマスクから、新しいポリゴントラックを作成します。既存トラックの延長、途中での対象追加、テキストによる検出は行いません。

## 対象と範囲を選ぶ

2Dジョブで開始フレームを表示し、メニューの「SAM2: ポリゴンとマスクを追跡」または「SAM3.1: ポリゴンとマスクを追跡」を開きます。
追跡可能な図形は初めに全て選択されています。チェックを外して対象を絞るか、全解除して必要な対象だけを選びます。開始フレームに対象がなければ、先にポリゴンまたはマスクを作成してください。

順方向は後のフレーム、逆方向は前のフレームへ進みます。開始と終了を指定し、「選択した対象を追跡」を実行します。開始と終了の両フレームを含み、フレーム番号の差は最大10,000、対象は1個から16個です。
この範囲は処理成功を保証する値ではありません。状態と出力サイズにも上限があるため、初めは短い区間で確認してください。

ロック中、画像外を表すoutsideの状態、回転付きの図形、既存トラックは開始対象にできません。削除済みのフレームは処理せず、その分だけ範囲を延長することもありません。

## 追跡結果を確認して保存する

全処理が成功すると、選んだ開始図形を新しいポリゴントラックへ置き換えます。ラベル、グループ、属性を引き継ぎ、選んでいないアノテーションと既存トラックは変更しません。
結果を確認し、必要な修正を行ってSaveで保存します。完了しただけではサーバーへ保存されません。反映した結果はUndoでまとめて取り消せます。

マスクは穴や離れた領域を含む状態で開始入力に使いますが、出力トラックは最大の外周ポリゴンだけです。穴と最大領域以外の分離した領域は保持しません。画像用SAMのマスク生成とは異なる制約です。

## 中止と失敗

中止やエラーで結果を適用しなかった場合は、元の図形を保持し、途中までの追跡結果を反映しません。追跡中に開始図形を編集、削除、ロックした場合も、結果の適用前の検査で拒否します。
追跡中はタブを閉じたり別ジョブへ切り替えたりせず、完了または中止を確認してください。ブラウザーを閉じた後の途中再開はありません。Redisに推論状態が残っていても、画面の進行状態が復元されるわけではありません。

## 開発と確認

共通UIはcvat-ui/plugins/sam2/src/ts/tracking-dialog.tsx、操作の適用はaction.ts、フレーム順と再試行はtracking.ts、選択と範囲検査はselection.tsにあります。
SAM3.1のプラグインはこの共通処理へ独立した関数IDを渡します。既存ワークフロー用のアクション名とパラメーター名は実装内で維持しています。
逆方向では画像を降順に渡し、結果をフレーム順に並べます。指定範囲の外へ結果が広がらないようoutsideの境界を設けます。

```bash
node cvat-ui/plugins/sam2/tests/run-tests.cjs
```

この試験は小さなCVAT契約用定義と代替応答で制御を確認します。実モデルの精度、実ブラウザー、実Redis、GPU容量の検証ではありません。
受入確認では両モデルについて、ポリゴン入力、マスク入力、順方向、逆方向、削除フレーム、対象選択、中止、開始図形の変更、Undo、Save後の再読込を確認します。
モデル固有のGPU確認と状態保存の設計は、[SAM2の設計](../sam2/design.md)と[SAM3.1の設計](../sam31/design.md)を参照してください。
