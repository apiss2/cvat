# 追加機能の導入と運用

[追加機能の一覧](../README.md)

このページは、CVATの環境を構築して管理する人向けの案内です。画面での操作は[アノテーション操作の一覧](../annotation/README.md)を参照してください。

## 導入して機能を選ぶ

| 作業 | 文書 |
| --- | --- |
| 初めて環境を構築する | [導入と共通設定](installation.md) |
| 設定名と必要なサービスを確認し、機能を切り替える | [拡張機能の管理](management.md) |
| SAM2やSAM3.1のモデルと重みを選ぶ | [モデルの選択と配備](model-selection.md) |
| ONNXモデル管理の接続先を設定する | [モデル管理サービスの配備](../model-registry/deployment.md) |

このフォークに付属する管理コマンド **`cvatctl`** は、CVAT本体と追加機能のビルド、起動、停止をまとめて扱います。設定ファイルの `CVAT_EXTENSIONS` で使う機能を選ぶと、必要な画面プラグインとサービス構成が反映されます。画面だけの機能も同じ方法で管理します。

設定項目は[設定例](../../components/extensions/config.example.env)に機能別にまとめています。まず共通設定を確認し、次に使う機能の設定を行ってください。既存環境では設定例で全体を置き換えず、現在の保存先と秘密情報を維持します。

## 更新と復旧を行う

| 作業 | 文書 |
| --- | --- |
| 検証した変更を実行環境へ反映する | [更新手順](update.md) |
| 更新前の状態から変更分を保存する | [増分バックアップ](incremental-backup.md) |
| データ、設定、使用イメージを保存して復旧する | [バックアップと復元](backup-restore.md) |
| モデル管理の資源制限や障害を調べる | [モデル管理の保守](../model-registry/operations.md) |

更新では現在のコードと設定で処理を止めてから、コード、機能選択、保存先を変更します。バックアップにはCVATのデータと、有効な拡張の保存先と秘密情報を含めます。モデルや機能の選択を変えた場合、対応するイメージの準備と、実際の操作確認が必要です。

## 開発時の管理対象を確認する

新しい機能を追加する場合は、[拡張機能の管理](management.md)にある開発手順と、[文書とテストの保守ルール](../development.md)を参照してください。形式の登録、画面の入口、追加サービスは有効化の範囲が異なります。たとえばタスク説明の取り込み形式は常時登録され、説明を画面に表示する機能だけを選択できます。各機能の説明で、無効化したときに残る処理と保存データを確認してください。
