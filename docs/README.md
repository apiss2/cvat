# このフォークの追加機能

この文書は、CVATに追加した機能を使う人と、環境を管理する人のための入口です。標準のアノテーション操作は[CVAT公式ドキュメント](https://docs.cvat.ai/docs/)を参照してください。

## 初めて読む場合

導入済みの環境を使う場合は、以下の一覧から行いたい作業を選んでください。まだ環境を構築していない管理者は、[導入と共通設定](extensions/installation.md)から始めます。各機能の設定名や追加サービスの要否は、[機能の管理一覧](extensions/management.md)で確認できます。

### データを取り込む

| 機能 | できること |
| --- | --- |
| [DICOM取り込み](annotation/dicom-import.md) | 医用画像のDICOMファイルから、静止画または動画のタスクを作成します。 |
| [アノテーション取り込み](extensions/project-annotation-import.md) | プロジェクト内の既存タスクへ、アノテーションをまとめて追加または置換します。 |
| [タスク説明の一括登録](extensions/task-guide-import.md) | MarkdownやJSONから、各タスクの作業説明や検査レポートを登録します。 |
| [専用形式の入出力](itgformat/README.md) | 領域と矩形を保存する独自のファイル形式「ITGformat」を読み書きします。 |

画像を新規登録する操作、既存画像のアノテーションを更新する操作、説明文を登録する操作は別です。入力する内容に合う文書を選んでください。

### 画像を確認して編集する

| 機能 | できること |
| --- | --- |
| [フレーム移動](annotation/frame-navigation-filter.md) | タグなどの条件に合う画像へ移動しながら、他の図形も表示して編集します。 |
| [長さの表示](annotation/physical-measurements.md) | DICOMから保存した画素間隔を使い、折れ線の長さをmmで表示します。 |
| [タスク情報の表示](extensions/task-context.md) | 作業説明、患者情報、検査条件などをタスク詳細と作業画面で確認します。 |
| [条件付きエクスポート](annotation/filtered-export.md) | 保存済みアノテーションの条件に合う画像と、そのアノテーションを出力します。 |

### モデルで下書きを作る

| 機能 | できること |
| --- | --- |
| [モデル登録](model-registry/README.md) | ONNX形式のモデルをブラウザーから登録し、領域分割、物体検出、分類に使います。 |
| [画像を選んで実行](annotation/selective-ai.md) | タグの条件や画像一覧から対象を選び、自動アノテーションを実行します。 |
| [SAM2](sam2/README.md) | 点や矩形で指定した対象のマスクを作成します。動画の追跡にも対応します。 |
| [SAM3.1](sam31/README.md) | 点や矩形からマスクを作成し、動画を追跡します。実験的な機能で、重みの事前配置が必要です。 |
| [UltraSAM](ultrasam/README.md) | 超音波画像で点を指定し、対象のマスクを作成します。 |
| [動画の追跡](annotation/tracking.md) | SAM2またはSAM3.1で、開始画像の図形からポリゴンのトラックを作成します。 |

## 環境を管理する場合

設定の作成、起動、更新、バックアップは[導入と運用の案内](extensions/README.md)にまとめています。このフォークに付属する管理コマンド **`cvatctl`** が、選択した機能に必要な画面とサービスをまとめて管理します。コマンドは、特記がなければリポジトリのルートで実行します。

モデル管理サービスを別ホストに置く場合は[接続と配備](model-registry/deployment.md)、資源制限や障害を調べる場合は[保守](model-registry/operations.md)を参照してください。

このフォークではGitHub Actionsを無効にしています。試験とビルドは、各ページのコマンドをローカルで実行します。トップREADMEの `Upstream CI` バッジは上流CVATの結果であり、このフォークの検証結果ではありません。構成確認、単体試験、実GPUでの推論、ブラウザーでの操作確認は、それぞれ別に実施します。

## 開発する場合

登録するモデルを作る人は[モデルの実装仕様](model-registry/model-development.md)を参照してください。フォークの機能を変更する人は、[開発方針](../AGENTS.md)、[文書とテストの保守ルール](development.md)、[サーバーと配備設定の案内](../components/README.md)、[画面拡張の案内](../cvat-ui/plugins/README.md)から実装を確認できます。

各実装ディレクトリのREADMEは概要と文書への入口に留め、操作や仕様の正本はこの `docs/` 配下で管理します。

## 文書を更新する場合

現行の仕様と再利用する手順は既存の正本を更新し、その作業での調査結果や実行ログは作業報告に記載します。文書を増やす基準、説明の順序、テストの配置、移動時の確認は[文書とテストの保守ルール](development.md)にまとめています。
