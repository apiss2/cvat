# UltraSAMの推論とCVATへの接続

[UltraSAMの案内](README.md) / [導入と検証](operations.md)

## 接続とコードの分担

拡張名ultrasam、関数ID pth-ultrasam-interactor、表示名UltraSAM (GPU)を使用します。CVAT標準のinteractor APIで現在画像と正負の点を受け取り、1対象の二値マスクを返します。専用のCVAT API、UIプラグイン、DB、動画セッションは作成しません。

[Nuclio実装](../../serverless/pytorch/camma/ultrasam/nuclio/)が入力検査と推論を担当し、[共通生成処理](../../components/extensions/functions.py)と[ビルド設定](../../components/ultrasam/build.json)で配備します。モデルは起動時に読み込み、試行推論後に受付を開始します。

直前の画像特徴をワーカーごとに再利用し、画像寸法と内容のSHA-256が変わる場合は再計算します。特徴の切り替えから推論までをロックし、要求間で画像と点が混在しないようにします。点は毎回の要求だけを使い、推論履歴を共有しません。

## 公式モデルと点の扱い

公式OpenMMLabの画像特徴抽出、マスク推論と重みを使用します。CVAT側からの複数の正例点と負例点を1対象のプロンプトとしてまとめ、符号と座標をモデルの入力表現へ変換します。

3個の候補のうち予測IoUが最大のマスクを選択します。予測した矩形やマスクを次のプロンプトへ置き換える自動的な再推論は行いません。単一点では公式初回推論のlogitと予測IoUを比較し、複数の正負点では操作、座標、保存結果を別に検証します。

## 画像と座標の変換

RGB画像を公式FixScaleResizeで縦横比を保持して長辺1024画素へ合わせ、DetDataPreprocessorで正規化し、右と下に余白を追加します。点には縦横それぞれの実際の縮小率と、公式の前処理に合わせた0.5画素の補正を適用します。

選択した候補のlogitを余白込みの1024画素へ双線形補間し、余白を除去し、元の寸法へ補間した後に閾値0で二値化します。二値化したマスクを先に拡大する処理とは境界が変わるため、モデル出力と原寸復元は別の試験で確認します。

## 入力と応答

| 項目 | 条件 |
|---|---|
| 画像 | RGBへ変換し、16,777,216画素以下、要求本文32 MiB以下。 |
| 座標 | 数値の[x, y]で、0以上かつ画像の幅と高さ未満。 |
| 点数 | 正例点1個以上、正負の合計128個以下。 |
| 対象外 | obj_bboxによる矩形、動画追跡。 |

```json
{"image": "BASE64_ENCODED_IMAGE", "pos_points": [[240, 160]], "neg_points": [[320, 190]]}
```

応答はCVAT interactor version 2のmaskです。最小外接矩形で切り出し、行方向のランレングスと両端を含むx0、y0、x1、y1をpointsに格納します。先頭は背景の連続長で、最初が前景なら0です。1画素だけが前景の場合の例です。

```json
{"shapes": [{"type": "mask", "points": [0, 1, 240, 160, 240, 160], "attributes": []}]}
```

前景なしはshapesが空の配列です。不正な入力を正常な空マスクとして返しません。入力エラーはHTTP 400または413、内部推論失敗は500です。関数のエラーログへ画像本体と点列は記録しません。

## 管理、GPU、ネットワーク

cvatctl buildはCVATなどの共通イメージを準備し、upまたはdeploy-ultrasamが関数をビルドして配備します。up --no-buildは既存イメージを使い、downはdashboardと管理対象関数を停止します。UltraSAMだけを使う場合はSAMの追跡用Redisを起動しません。

NVRTC本体と開発用リンクを同じ版で導入します。ビルド時はGPUなしで読み込みとコンパイル、実行時はGPUのcuDNN畳み込みとUltraSAM推論を検査します。子プロセスの異常終了は終了コードやシグナルを初期化エラーへ含めます。準備完了までの待機は300秒、要求処理の上限は120秒です。

ULTRASAM_GPU_DEVICEはCUDA_VISIBLE_DEVICESを設定します。モデルのcuda:0は指定したGPUを指しますが、GPUの専有やアクセス分離は保証しません。関数はCVATの共有ネットワークへ接続し、HTTPポートはホストへ公開せず、dashboard経由で呼び出します。dashboardの管理ポートはループバックだけに公開します。

## 変更時の確認対象

CVAT変更時はinteractorの要求、version 2のmask応答、確定と保存を確認します。Nuclio変更時はnuctlの版、ビルド、GPU、ネットワーク、停止と復元を確認します。UltraSAMと依存ライブラリの変更時は重みと構成、点の変換、公式との単一点比較、複数点の実推論を確認します。

ビルド成功、GPU推論成功、実画像での境界の妥当性は別に確認します。試験コマンド、利用条件、依存関係の記録は[運用と検証](operations.md)を参照してください。
