出力ラベルと変換

推論結果と、CVATで使用するラベルを対応付けます。

Polygon変換

周長に沿って点を配置した後、最後と最初を含む隣接頂点の距離を確認します。条件を満たすpolygonを作れない小領域は除外します。穴は外周の内側として塗りつぶされます。

3

ファイルと試験画像

公開前に、登録するモデルで試験画像を推論します。

ModelBaseを継承したModelクラスのloadとpredictを実装します。入力画像はRGB形式です。更新の検証に失敗した場合は公開中の版を維持します。

試験推論が成功すると、CVATから利用できます。
ZIPでまとめて登録する

manifest.json、model.py、宣言したONNXファイル、sample.pngまたはsample.jpgをZIP直下に配置します。ZIP内の設定を使用します。フォームが更新状態の場合は同じモデルを更新します。
