# SAM2 / SAM3.1 の追跡操作

開始フレームのポリゴン・マスク図形から、新規ポリゴントラックを作成します。
CVAT本体を変更せず、既存の拡張用アクションAPIを使います。既存トラックの延長とテキスト検出は提供しません。

1. 2Dジョブで、開始位置のフレームを表示します。
2. `Menu → SAM2: ポリゴンを追跡…` または `SAM3.1: ポリゴンを追跡…` を開きます。
3. 対象を選びます。初期状態では追跡可能な図形をすべて選択しています。全選択・全解除も使えます。
4. 前方向または逆方向と、開始・終了フレームを指定して追跡します。
5. 結果を確認し、必要なら修正して `Save` で保存します。

最大16対象、開始・終了のフレーム差は最大10,000です。両端のフレームを含みます。
処理中の対象数・状態サイズ・結果座標数には上限があります。まず短い区間で確認してください。
ロック中、outside、回転付きの図形と、既存トラックは初期対象にできません。

マスクの穴や離れた領域は初期入力として保持しますが、出力は最大の外周ポリゴンです。
対象外の図形と既存トラックは変更しません。対象の編集中の変更は検出し、結果の適用を拒否します。
削除済みフレームは処理しません。範囲外へ追跡結果が広がらないようoutsideを追加します。
逆方向では画像を降順に渡し、結果のキーフレームをフレーム順に保存します。

完了結果はUndoで一括取消できます。処理完了だけではサーバーへ保存されません。
エラー・中止で結果を適用しなかった場合、元の図形を維持します。

SAM3.1の配置と認証方式を変更した理由は[配備手順](README.md#checkpoint-placement-and-deployment)を参照してください。
モデル・重みの互換性や短いテストの成功は、実動画での精度・長時間追跡の保証にはなりません。
